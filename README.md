# Newton from scratch demos

These are pure-standard-library Python demonstrations for the Newton people
series film. Run `./run_all.sh` with Python 3. It writes per-demo JSON files
under `runs/`, the combined `values.json`, and a short `demo-output.txt`.

The orbit paths are generated by integrating Newtonian inverse-square gravity;
they are not hand-authored animation paths. Each orbit stores sampled points,
radius extrema, outcome, and energy drift. The five launch cases begin at
Earth radius plus 300 km. The prism indices are deliberately illustrative.

The script also runs numerical invariant and convergence checks. There are no
third-party dependencies, network calls, or render steps.

## Source-relative use

Run the launcher from any working directory:

```sh
/path/to/newton-from-scratch/code/run_all.sh
```

The launcher changes into its own directory before running, so all output
paths are relative to this `code/` folder. A caller may also run
`python3 newton_demos.py` from inside `code/` to regenerate the JSON snapshot
without the readable report. The animation should load `values.json` or the
scene-specific files in `runs/` relative to the project asset directory.
